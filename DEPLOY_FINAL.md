# Final deployment

1. Keep your currently working `assets/card.mind` file. Copy it into this package at `assets/card.mind` before deployment.
2. Upload all files and folders from this package to the root of the existing GitHub repository.
3. Replace the existing `index.html`, `style.css`, `js/`, and `assets/models/` files.
4. Do not delete your working `assets/card.mind`.
5. Commit the update and wait for GitHub Pages to finish deploying.
6. Test in an Incognito tab or append `?build=final1` to the URL.

The final layout is controlled in `js/ar-scene.js`. The animated flag and its shader-rendered 24-spoke Ashoka Chakra are controlled in `js/effects.js`.
